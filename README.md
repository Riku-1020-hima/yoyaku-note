# ヨヤクノート

美容室・サロン・整体など、メニューと担当者で予約を受けるお店向けの予約管理Webアプリです。お客さんはスマホから会員登録なしで予約でき、お店は電話の予約も同じ予約表で管理できます。

## 主な機能

- **お客さんの予約ページ**(ログイン不要・スマホ向け):メニュー → 担当者(指名/指名なし)→ 空いている日時 → 名前と電話番号
- **空き時間の自動計算**:営業時間・定休日・お休み・担当者の出勤日・できるメニュー・すでに入っている予約・メニューの所要時間から計算
- **予約ごとの確認ページ**:予約の内容、キャンセル(締め切りまで)、カレンダーに追加(.ics)
- **予約表**:縦が時刻・横が担当者の1日の表(スマホでは担当者ごとの一覧)。空いているマスから予約を入れられる
- **電話予約の手入力・変更**:同じ担当者の予約と時間が重なると入れられない(ダブルブッキング防止)
- **来店の記録**:来店済み・無断キャンセル・キャンセル
- **お客さん一覧**:電話番号が同じ予約をまとめて、来店回数・前回の来店日・次の予約・お店のメモ
- メニュー(所要時間・料金・できる担当者)、担当者(出勤する曜日)、お休み(臨時休業・担当者の休み)、受付ルール(何時間前まで・何日先まで・キャンセルの締め切り)、使い方ガイド

## 空き時間の決め方(app/Services/SlotFinder.php)

1. その日がお店の営業日か(曜日の営業時間・お店の休み)
2. そのメニューができて、その日に出勤している担当者は誰か(担当者の休みも見る)
3. 開店から設定の間隔(30分など)で開始時刻を並べ、「開始 + 所要時間」が閉店までに終わり、その担当者のほかの予約と重ならない時刻だけ残す
4. 「◯時間前まで」「◯日先まで」の受付ルールの外は出さない

「指名なし」のときは、空いている担当者のうち、その日の予約が少ない人に入れます。
同時に2人が同じ時間を予約しても二重にならないよう、保存する前にデータベースで順番待ち(ロック)をして空きを確かめ直します(app/Services/BookingService.php)。

## 使っている技術

- Laravel 13 / PHP 8.4
- Blade + Tailwind CSS 4(JavaScript はほとんど使っていません)
- SQLite(開発)/ MySQL(本番:Laravel Cloud)

## 動かし方(Laravel Herd)

```bash
bash ~/Herd/yoyaku-note-setup/setup.sh
```

- お店の画面:http://yoyaku-note.test (`demo@example.com` / `password`)
- お客さんの予約ページ:http://yoyaku-note.test/r/demo

デモデータには、架空の美容室(担当者3人・メニュー6つ・3週間前から2週間先までの予約)が入っています。予約の日付は、データを入れた日を基準に作られます。

### テスト

```bash
php artisan test
```

## 公開デモ版の設定

環境変数で `DEMO_MODE=true` にすると、ログイン画面にデモ用アカウントとお客さん側のページへのボタンが表示され、新規登録とログイン情報の変更ができなくなります。毎日4時(日本時間)に `php artisan demo:reset` でデータが初期状態に戻ります。
